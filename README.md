Historically continuous with drafts labeled *Vortex Æther Model (VAM)*. The public name and notation today are **SST**. VAM documents remain provenance — not the living Canon.

> If spacetime can bend, why shouldn’t it knot?

> *Physics is interpreted as the dynamics of a continuous medium whose stable, delayed, and topologically organized motions appear effectively as particles, clocks, fields, and spectra.*

## 📜 Origin (2012 → now)

SST did **not** begin as a fluid-mechanical model with a preselected set of hydrodynamic constants. The earliest written development asked whether atomic excitation, the energy–frequency relation, and mass as a **bound rotating state** could be understood as a classical, local, **impedance–resonance** interaction.

Notebooks from **2012** and a first synthesis in **July 2013** spoke the language of capacitance, dielectric response, oscillator stiffness, and free-to-bound mode transfer. Circulation, vorticity, toroidal cores, knots, and relational vortex clocks arrived **later** — a dynamical substrate for that older programme, not a rewrite of history.

**Canonical origin statement** (from Canon v0.8.36):

> SST originated as an impedance–resonance attempt to explain atomic excitation, the proportionality between energy and frequency, the emergence of mass from a bound rotating state, and the relation between internal material speed and the free propagation speed. Vorticity and knot topology are later dynamical languages introduced to make that program local, conservative, geometric, and falsifiable.

### How to read the Canon

| Tag | Meaning |
|-----|---------|
| **[ORTHODOX]** | Established physics or mathematics |
| **[DERIVED]** | Consequences from definitions and assumptions of this SST layer |
| **[SPECULATIVE]** | Conjectural extensions — not yet closed as theorems |

Optional role labels (*Definition*, *Benchmark*, *Constraint*, …) qualify *how* to read a statement; they do **not** replace the primary tag.

**Rosetta principle:** whenever a standard description already works, SST must map to it before claiming any deeper reinterpretation. Orthodox constraints (spectroscopy, relativistic consistency, low-energy QM recovery) are not overridden by enthusiasm.

### What is structurally “canon-level”

- Primitive constant chain and Compton / horn–circulation anchoring
- Swirl-Clock as coarse-grained relational time factor
- Delay-induced mode selection as preferred discreteness mechanism
- Atomic bridge and spectroscopic sectors as **compatibility filters**
- Topology-first programme for mass organization
- Geometry certification + KnotPlot→Ridgerunner computational provenance

### What remains open (and is labeled as such)

- Full Standard Model gauge sector from first principles
- Complete particle spectra from topology alone
- Many-body shell filling / exclusion without importing QM rules
- Showing that delay + topology reproduce the observed quantum rule set without smuggling it in

The Canon is a **structured reference**, not a claim that every sector is already theorem-level. That honesty is a feature.

## ⚙️ SSTcore (sibling)

**SSTcore** is the hybrid engine: shared C++23 numeric core, **pybind11** Python package, and **Node.js** N-API addon — install either (or both):

```bash
# Python
pip install SSTcore
python -c "import SSTcore; print(SSTcore.__version__)"   # expect 0.8.36

# Node.js
npm install sst-core
```

What you get:

- Knot / filament / fluid kernels (Biot–Savart, helicity, vortex rings, Gilbert ideal + f-series catalogs)
- Geometry certificates and KnotPlot→Ridgerunner **pipeline provenance**
- Canon API ladder **0.8.19–0.8.36** (action-phase clocks, density ontology, transverse projector, Maxwell swirl-tonic diagnostics, …)
- Bundled `resources/ideal/`, `Knots_FourierSeries/`, knotplot INDEX

Full story: [SSTcore README](https://github.com/Swirl-String-Theory/SSTcore#readme) · Coverage: `docs/BINDING_COVERAGE.md` in that repo · Examples: paired `example_*.py` / `example_*.ts`
